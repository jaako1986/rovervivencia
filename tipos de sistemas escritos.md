## Sistemas escritos

Los sistemas escritos permiten transformar un mensaje utilizando una **regla conocida por quien lo escribe y por quien debe interpretarlo**.

Esa transformación puede ser muy sencilla, como reemplazar una letra por otra, o utilizar números, posiciones, símbolos y combinaciones para representar el alfabeto.

En actividades scout se utilizan principalmente como ejercicio de **observación, lógica, memoria y comunicación**. Resolver una clave no consiste solamente en conocerla: muchas veces hay que descubrir primero qué regla fue utilizada.

### Codificar y decodificar

Todo sistema parte de un mensaje original.

**MENSAJE → REGLA → MENSAJE CODIFICADO**

Quien lo recibe realiza el camino inverso:

**MENSAJE CODIFICADO → REGLA → MENSAJE**

A este proceso lo llamaremos:

**CODIFICAR**
Transformar el mensaje utilizando una regla.

**DECODIFICAR**
Aplicar esa regla para recuperar el mensaje original.

Si ambos conocen la regla, el intercambio es sencillo. Si la regla forma parte del desafío, primero habrá que descubrirla.

## Diferentes maneras de transformar un mensaje

### Sustitución

Cada letra se reemplaza por otra letra, número o símbolo.

`A → D`
`B → E`
`C → F`

Claves como **César** o **Murciélago** utilizan distintas formas de sustitución.

### Posición

La letra se identifica por el lugar que ocupa dentro de una tabla, cuadrícula o sistema acordado.

`23 → fila 2 · columna 3`

En lugar de representar directamente una letra, el código indica **dónde encontrarla**.

### Símbolos

Cada letra se representa mediante una figura, línea o combinación gráfica.

`LETRA → SÍMBOLO`

Una vez conocida la correspondencia, el mensaje puede escribirse y leerse utilizando solamente esos signos.

---

## Una clave necesita una regla

Podemos inventar prácticamente cualquier sistema siempre que mantengamos una correspondencia clara.

Por ejemplo:

`A = ▲`
`B = ●`
`C = ■`

La dificultad no está en utilizar símbolos extraños, sino en mantener la misma regla durante todo el mensaje.

Una buena clave debe ser:

**CONSISTENTE** — la misma regla siempre.
**REPETIBLE** — puede utilizarse nuevamente.
**INTERPRETABLE** — quien conoce la regla puede resolverla.

> **Un código complicado sin una regla clara no es una clave: es solamente un mensaje imposible de leer.**

---

## Código no significa secreto

Las claves scout pueden utilizarse para ocultar mensajes durante juegos, búsquedas o desafíos, pero su objetivo principal en este manual es aprender distintas formas de **representar y transmitir información**.

Algunos sistemas fueron creados específicamente para ocultar información. Otros, en cambio, nacieron para permitir que un mensaje pudiera viajar utilizando medios diferentes.

El ejemplo más importante de estos últimos es el **código Morse**.

Antes de llegar a él veremos algunas claves sencillas de sustitución, posición y símbolos para comprender cómo puede transformarse un mensaje escrito.
